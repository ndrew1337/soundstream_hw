# SoundStream Homework

This is my solution for homework about the SoundStream codec ([SoundStream: An End-to-End Neural Audio Codec](https://arxiv.org/abs/2107.03312)).

The original template for this project was made by Petr Grinberg here: [Blinorot/pytorch_project_template](https://github.com/Blinorot/pytorch_project_template).

## Notebooks

In the [`notebooks/`](notebooks/) folder:

- [`demo.ipynb`](notebooks/demo.ipynb) — demo of the trained codec (encode/decode on a sample audio file).
- [`kaggle_training.ipynb`](notebooks/kaggle_training.ipynb) — notebook for running training on Kaggle; includes final full-test metrics (STOI / NISQA).
